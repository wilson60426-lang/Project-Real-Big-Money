# PRBM v0.9.11｜繁體中文金融研究助手

這個版本從 **新聞標題與英文財經術語** 入手，協助剛開始研究金融市場的人建立查核清單，而不是發出買賣建議。

## 使用方式

1. 下載最新 GitHub ZIP 並解壓縮，在含有 `app.py` 的資料夾開啟命令提示字元。
2. 初次使用輸入 `python -m pip install -r requirements.txt`。
3. 輸入 `python -m streamlit run app.py`。
4. 打開 **📚 金融研究助手**，選擇以下模式之一：
   - **自己貼上新聞標題**：貼入最多 600 字的英文或中文標題，查看事件分類、金融術語、可能影響及查核建議。
   - **從免費新聞選一則**：瀏覽公開 RSS 標題，保留發布時間、來源與原始新聞連結。
   - **金融英文詞典**：查詢 EPS、Guidance、CPI、PCE、FCF、Non-GAAP、ETF 等英文與繁中解釋。
5. **📰 全球金融快報** 和 **📈 K 線研究室** 也能選新聞閱讀相同的白話分析。

## 判讀示例

標題：`Nvidia beats earnings estimates but lowers revenue guidance`

研究助手應提醒：
- 這可能是「企業財報與財測」類事件。
- 應先分開核對實際 EPS、營收、分析師共識預估與未來財測。
- 財報優於預期不等於股價必漲，因為未來展望、估值與預先定價都會影響市場反應。

請以該則新聞的實際官方財報原文為準，上方是假設示例。

## 關鍵限制與隱私

- 核心事件分類、術語說明在本機以 **規則與詞典** 產生，不是生成式 AI，也不代表讀取或核實新聞全文。
- 免費 RSS 可能延遲或缺漏；Google News 是索引，並非原始發布機構。
- 使用者**只有主動勾選翻譯**時，英文標題才會交由外部免費翻譯服務處理；翻譯可能不準確或失敗，始終以原標題與官方原文為準。
- 不提供特定標的的勝率預測；新聞與價格變化的同時發生**不證明因果關係**。
- 新聞研究助手沒有接入付費即時新聞、SEC 全文財報檢索或可查證的 AI 摘要模型；未接入時不應聲稱功能已存在。

