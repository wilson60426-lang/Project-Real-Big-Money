# PRBM v0.9.13｜美股財報 × 新聞 × K 線事件研究

本次在原本的 **🧾 美股財報研究室** 加入公告日的行情對照與近期新聞（免費 RSS）。它是**研究工具**，不是財報消息套利系統，也不提供買賣建議。

## 使用方式

1. 下載 GitHub 最新 ZIP，解壓縮後，在有 `app.py` 的資料夾開啟命令提示字元。
2. 初次啟動：`python -m pip install -r requirements.txt`。
3. 執行：`python -m streamlit run app.py`。
4. 選擇 **🧾 美股財報研究室**，挑選 NVDA、AAPL 等支援的美國上市公司。
5. 開啟「📊 載入營收、EPS、毛利率與市場預期」，依序查看：
   - **① 季度財報**：營收、毛利率、營業利益、淨利，會計季度「期末日」；
   - **② EPS 實際 vs 供應商預估**：已公布 EPS、EPS Estimate，供應商「公告時間」；
   - **③ 白話數據**：成長、毛利率與缺漏資料；
   - **④ 財報公告 × K 線**：用美東時間把盤前／盤後公告對到已完成的美股日 K；
   - **⑤ 近期新聞**：自行勾選載入公司的免費新聞，核對原始標題、來源並展開詞彙解釋。

## 事件研究的計算規則

本版以供應商提供的、**含時區且有已公布 EPS 的公告時間**作為觀察時點，使用 `America/New_York` 時區，能處理美國夏令時間變換。僅使用**已完成的日 K 收盤價**：

| 事件時間 | 前後收盤價選取 |
|---|---|
| 盤前，09:30 美東時間以前 | 前一交易日收盤 → 公告當日收盤 |
| 盤後，16:00 美東時間起 | 公告當日收盤 → 下一交易日收盤 |
| 休市日發布 | 公告前最近一個已完成收盤 → 休市後首個完整交易日收盤 |
| 盤中發布、沒有明確時區或時間模糊 | 不計算；單靠日 K 不能將事件影響隔離出來 |
| 缺少收盤、交易日間隔過大、未來／未公布 EPS | 不計算；明確提示原因 |

描述性價格變化：

```text
股價變化（%） = (公告後第一個可用完整收盤價 / 基準收盤價 - 1) × 100
```

**此數值不等於財報造成的價格影響、異常報酬或含股利的投資總報酬。** 本版未扣除市場指數、產業、匯率、預期已反映程度或其他同時發布的消息；Yahoo Finance 歷史報價也可能因股票分割等事件重編。

## 嚴格區分資料來源

- `yfinance` 從 Yahoo Finance 取得財報、EPS 公布紀錄與未調整的日線 OHLC。價格歷史僅供研究，非保證即時資料。
- 供應商標示的 EPS Estimate **未經公告前凍結時間點驗證**，不能自動稱為真正公告前市場共識。
- 季度損益表的 **期末日不是財報公告日**，不能依表格排序把兩張表當同一筆公告。
- 新聞來自近期免費 RSS；對公司名稱的比對只是**標題關鍵字關聯**，不等於新聞直接描述該次歷史財報。歷史公告可能找不到同期新聞。
- 公司官方 10-Q、10-K、8-K 等文件應到 [SEC EDGAR](https://www.sec.gov/edgar/search/) 核對。
