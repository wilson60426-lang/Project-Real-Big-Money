# PRBM v0.9.14｜美股財報事件的 SPY 同期市場比較

本版延伸既有 **🧾 美股財報研究室**，新增與 SPY（SPDR 標普 500 ETF）的同期收盤價比較，避免把「整個大盤也漲」忽略掉。

## 操作

1. 下載 GitHub 最新 ZIP，解壓縮後到含有 `app.py` 的資料夾。
2. 初次安裝：`python -m pip install -r requirements.txt`。
3. 開啟：`python -m streamlit run app.py`。
4. 選擇 **🧾 美股財報研究室**，挑選 NVDA、AAPL、MSFT 等支援公司，開啟財報資料載入。
5. 在 **④ 財報公告 × 美股 K 線** 查看「同期 SPY 大盤比較」，點選一筆公告閱讀繁體中文說明。

## 計算規則

股價事件視窗仍以先前保守的美東時區、財報公告時間與已完成美股交易日決定（詳見 `docs/earnings_news_chart.md`）。

```text
個股同期價格變化 (%) = (個股對照日收盤價 ÷ 個股基準日收盤價 − 1) × 100
SPY 同期價格變化 (%) = (SPY 對照日收盤價 ÷ SPY 基準日收盤價 − 1) × 100

個股相對 SPY（百分點）= 個股同期價格變化 (%) − SPY 同期價格變化 (%)
```

例如**純假設範例**：個股漲 10%，SPY 同期漲 2%，就代表個股相對 SPY 的「價格變化差額」為 **+8 個百分點**。這**不是**風險調整異常報酬，也不能證明事件導致個股跑贏。

## 資料品質與拒算條件

- 個股 EPS 公告必須有可靠可辨認的時間（包含時區、明確的盤前／盤後條件）及已公布值；事件尚未完成、盤中消息或缺少時區時，先不計算個股事件窗口。
- 僅使用 Yahoo Finance 可取得、已完成的美股日 K；不會把未收盤資料當作完成的交易日。
- **SPY 必須存在與個股事件分析完全相同的基準日和對照日**；沒有資料時不做 forward-fill、nearest-date 或其他補值，不計算市場差距。
- 兩套行情都是供應商歷史資料，並非交易所即時數據；比較不含配息、交易成本或風險調整，股票分割與其他公司行動可能影響長期可比性。
- 未提供風險模型、市場 Beta、產業對照、公告前歷史共識快照或排除其他消息的因果設計。SPY 是大盤參考，而非產業專屬對照。
- 同時保留原先公司財報、EPS 紀錄、相關免費新聞與原始來源查核。
