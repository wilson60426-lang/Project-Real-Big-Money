# PRBM v0.9.12｜美股財報研究室（免費資料來源）

此版本在 Streamlit 主選單新增 **🧾 美股財報研究室**，協助繁體中文使用者看懂美股季度財務數字，以及能夠取得的「EPS 已公布值 vs. 市場預期值」。

## 使用方式

1. 在 GitHub 下載最新 ZIP，解壓縮後進入包含 `app.py` 的資料夾。
2. 首次執行：`python -m pip install -r requirements.txt`。
3. 啟動：`python -m streamlit run app.py`。
4. 選擇 **🧾 美股財報研究室**，從 AAPL、MSFT、NVDA、AMZN、GOOGL、META、TSLA 選擇公司。
5. 開啟「載入營收、EPS、毛利率與市場預期」，查看兩張不同口徑的資料表及白話說明。

## 怎麼理解資料？

| 區塊 | 含義 | 不能假設 |
|---|---|---|
| 季度損益表 | 會計季度**期末日**的營收、毛利、營業利益、淨利與財報每股盈餘 | 期末日不是公告日，金額不一定是美元 |
| 營收年增率 | 只有存在接近去年同期的對應季度且基期營收大於零才計算 | 缺漏不是 0% 成長 |
| 毛利率 | 毛利÷營收，在兩者皆可取得且營收大於零時計算 | 毛利率不是淨利率 |
| EPS 公布紀錄 | Yahoo Finance 所提供的**公告日** EPS 預期／已公布 EPS | 不保證與財報 Diluted EPS 採相同會計口徑 |
| EPS 預期差距 | 同筆已公布紀錄之 `(已公布 EPS − 預期 EPS) ÷ |預期 EPS| × 100%` | 不等於股價漲跌幅，也不等於「勝率」 |
| 資料缺漏 | 明確標示取不到的欄位或資料源異常 | 不會填入猜測數字 |

## 資料來源與限制

- 透過 `yfinance` 讀取 Yahoo Finance **季度損益表**和 **歷史財報公告 EPS 預期與已公布值**；此來源並非企業 SEC 官方報告。
- 資料可能延遲、缺失、重編或採調整口徑；來源缺少 EPS 預期時，不能宣稱「超出市場預期」。
- 不將公布日當作季度期末，也不把兩張表同列視為同一季；未經原始文件驗證，**不聲稱已取得營收分析師共識或公司未來財測**。
- 幣別由供應商 `financialCurrency` 欄位提供；取得失敗就標成「未核實」。
- 目前不含 ETF、台股、加密貨幣基本面，亦非實時投資決策工具。
- 可透過 [SEC EDGAR](https://www.sec.gov/edgar/search/) 查證企業原始財報，亦可直接點應用內的 Yahoo Finance 財報頁。

`tests/test_fundamentals.py` 使用完全離線的模擬資料驗證季度口徑、EPS 預期差距、未公布 EPS、年增率以及缺漏數據處理。GitHub Actions 的結果需另行確認；版本已提交不代表 CI 已通過。
